GitHub Upload

Upload gambar langsung ke repo GitHub. Token disimpan di localStorage browser Anda.

⚠️ Cara membuat token:
  1. Buka GitHub → Settings → Tokens (Fine-grained).
  2. Buat token dengan Contents: Read and Write ke repo beritafaktanews.
  3. Copy token → paste di bawah.

Disimpan di localStorage, tidak di-commit. Kosongkan jika tidak ingin upload.
